# PicMerge

PicMerge 是一款简单易用的 Android 长图拼接工具，适合将多张截图、聊天记录、网页内容或照片合并成一张完整图片。

## 主要功能

- 一次添加多张图片并自由调整顺序
- 逐张设置保留区域，去除重复内容或无关部分
- 直接拖动裁切线，实时查看调整效果
- 支持像素级微调，方便精确定位
- 双指缩放查看图片细节
- 长按缩略图快速调整拼接顺序
- 实时预览最终长图
- 将结果保存为 PNG 图片

## 使用方法

1. 点击“添加图片”导入需要拼接的图片。
2. 点击缩略图选择要调整的图片。
3. 拖动起点和终点裁切线，确定保留范围。
4. 必要时使用微调按钮进行精确调整。
5. 长按缩略图拖动，调整图片拼接顺序。
6. 点击“预览长图”确认效果，然后保存图片。

## 适用场景

- 手机截图拼接
- 聊天记录整理
- 网页内容合并
- 应用界面长图制作
- 多张照片纵向合成
